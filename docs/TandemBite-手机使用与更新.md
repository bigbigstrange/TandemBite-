## 日常在手机上使用

每个账号只有一个厨房、一本生活账本。新增菜品、编辑菜谱、点菜、完成做饭、上传照片、记收支，保存成功后直接写入云端，**不需要开电脑或重新发布**。

菜品照片由你自己上传：厨房 → 添道菜 → 点照片区域 → 拍照或从手机相册选择 → 填菜名、分类 → 保存。也可以从菜品详情进入编辑，更换照片后保存。不上传照片时显示相机占位图。选择图片不等于已经保存；请等待保存成功提示。

绑定前正常使用；绑定后双方原有菜品、分类、做饭记录和历史账目一起合并，双方都能编辑。相同名称的分类合并，同名菜品保留。没有个人厨房、个人账本或空间切换入口。

解除绑定时，双方各得到当时完整内容的独立副本，都能继续编辑，之后停止同步。若将来重新配对，同一笔旧账不会直接重复计入；两份副本发生不同修改时，会先要求核对保留版本。

首次升级、绑定或解绑时可能显示“整理小厨房”。请保持网络连接；中途退出后重新进入首页可以继续，源数据仍保留在云端。

## 账本筛选

默认按月查看收入、支出及结余。点“日期／分类筛选”，可改成自定义起止日期，并全选或勾选八个支出分类中的几个。起止两天都计入。**筛选模式只统计支出，不包含收入**；点“恢复月度收支”返回原本的月度统计。明细、分类汇总与导出使用同一套筛选条件。

这里是人民币手工记账，不会扣款，不自动读取微信或银行卡账单。

## 2.3.1 奶油手账

这版采用你确认的“奶油手账”预览：暖奶油背景、偏橄榄绿的主按钮、软圆角纸张卡片和手写标题。正文与金额仍使用清晰的系统字体；真实菜品继续显示你上传的照片。

- 首页“去点菜”为大入口，“添道菜／记一笔”为两个次入口；保留原来的首页文案。点击小狗头像会有一句回应。
- 厨房保留概览和今天的餐单，拿手菜改为两列照片；点菜保留左分类、右侧上下滑动，顶部可直接进入菜品库与做饭记录。
- 账本明细按日期分组，功能图标改用统一细线图标。“统计”改为环形图＋分类金额列表：点分类，中心切换为该类金额；再点一次恢复合计。分类颜色固定，不会随金额排序变化。只有有支出的分类显示在图上；零支出显示中性底环和0.00，不生成虚拟占比。
- 月度、自定义日期、多分类筛选、收入、导出、删除恢复继续使用原有规则。图表只展示支出；分类筛选仍不包含收入。金额直接显示，不从0滚动计数。
- 按钮、收藏、勾选和筛选弹层增加短暂反馈。添菜／改菜谱／记账正式保存成功后出现小狗庆祝；页面立即返回，庆祝在返回页显示；“保存并再记一笔”直接在当前页显示。保存失败不会庆祝。可以在下一次真实操作时体验，不必添加演示账目。
- 草稿、待选餐单和共享收藏保持2.2.0的使用方式；选照片不再裁剪，上传预览按原比例展示。此次没有新增云服务或数据库迁移，**不需要部署云函数**。

## 2.2.0 新增体验

- 页面统一奶油底色、深棕标题、薄荷按钮、圆角及留白。标题使用可爱字体，正文和金额保持系统字体。继续保留左分类、右侧上下滑动选菜。
- 添菜、编辑菜品／菜谱、记账表单会自动暂存未完成的内容，返回后恢复。照片也随菜品草稿保存在本机；页面可点“清除草稿”重新填写。草稿仅存在当前设备，不会给伙伴共享，也不会跨账号或跨厨房恢复。清理微信数据或卸载后可能丢失；正式保存成功后才写入云端。
- 编辑过程中伙伴已修改云端内容，会保留旧草稿并阻止直接覆盖；可先“查看旧草稿”，核对后“放弃旧草稿”，再编辑最新版本。草稿原分类已不存在时，需重新选择分类。
- 点菜与菜品库之间切换，保留待选菜品、搜索、筛选和浏览位置；重新打开也可恢复未提交餐单。正式提交成功后清除待选餐单；“清空选择”主动取消选择。已被删除的菜不会继续恢复为待选项。
- 菜品旁的星星是**共同收藏**，双方看到同一份清单。全部列表中收藏置前（点菜页在各分类内置前）；“收藏”单独筛选。“常做”按点菜次数排序，并非按完成做饭次数计算。伙伴可以刷新页面查看刚改的收藏；短期缓存可能延后几秒显示。
- “记一笔”自动定位金额；常用备注可快速填入。“保存并再记一笔”成功后清空金额和备注，保留分类、收支类型和日期，继续记录下一笔。保存失败时保留原内容与重试编号，防止重试重复入账。
- 拍照或从相册选择后直接预览，不弹出裁剪步骤，也不提供“调整裁剪”。上传预览按照片原比例完整展示，保留“查看大图”；保存前仍会等比缩小大照片以提升加载速度。菜品库及菜单保留原有缩略图布局，菜品详情点击主图可查看完整大图。以前已经裁剪并保存的照片，如需恢复完整画面，请重新选择原照片保存。

## 这次怎样让手机更新

1. 在微信开发者工具打开本项目，点击 **编译／刷新**，确认没有红色错误。
2. 点击 **预览**，用管理员微信扫码，先检查厨房、点菜、账本和上传照片。预览还不会更新朋友的体验版。
3. 测试满意后，点击开发者工具顶部 **上传**，版本号填 `2.3.1`，备注填“伴食：奶油手账主题、环形统计、细线图标与小狗互动”。
4. 登录微信公众平台 https://mp.weixin.qq.com → **版本管理 → 开发版本**，找到刚上传的 `2.3.1` → **设为体验版**。
5. 你和朋友退出小程序，重新扫描体验版二维码。朋友须已加入体验成员，或申请后由管理员批准。
6. 在“我的”核对版本 `v2.3.1`。旧版本可能提示升级或无法访问整理后的厨房，请更新，不要重复注册或解绑。

**上传不等于设为体验版，体验版不等于公开正式发布。** 微信列表里的官方名称、头像需要在公众平台“小程序信息”另行设置，改页面代码不会修改这些平台资料。

## 以后改代码时要做什么

|修改内容|让手机生效的方法|
|---|---|
|文字、主题、页面、前端逻辑|保存 → 编译 → 预览 → 上传 → 设为体验版|
|`cloudfunctions/tandem/` 后端逻辑|部署 tandem；同时改页面时，也按上一行发布前端|
|其他云函数|部署实际修改的函数|
|数据库集合、规则、索引|在同一个云环境完成配置；上传前端不包含这些配置|
|手机里新增菜品、换照片或记账|保存成功即可，不需要开发者工具|

助手已明确报告部署完成的函数不用重复部署。自行部署时，右键对应云函数目录 →“上传并部署：云端安装依赖”。云函数部署会直接影响手机调用，不能用仅回退前端的方法回退数据库结构。

当前沿用已部署的2.2.0 tandem 后端。本次2.3.1仅改前端，不需要部署云函数，没有新增数据库集合或购买服务。手机更新仍需完成上述预览、上传和设为体验版步骤。

## 两台手机验收

- 保留真实绑定关系测试，不为测试随意解绑。
- 自己上传一张菜品照片并保存，退出页面重新进入，伙伴手机也能看见。
- 左侧点击分类，右侧上下滑选菜；保存餐单后双方打开做饭记录核对。
- 记录一笔实际花销，伙伴刷新后可见；修改和最近删除恢复正常。
- 自定义一段日期，选择两个支出类别，核对明细、汇总与CSV；恢复月度后收入仍正常。
- 另外一对朋友只能访问他们自己的厨房和账本。
- 填写菜名、选照片、填做法后返回，重新“添道菜”，核对草稿恢复；可以在确实需要添加的菜品上测试。
- 选择几道菜后切去菜品库、返回点菜，核对未提交选择仍在；菜品点星后伙伴刷新能看到共同收藏。
- 用一笔真实花销测试“保存并再记一笔”，核对只新增一笔，金额清空、分类与日期保留。不要为验收往真实账本里加入演示金额。
- 手机核对选照片后直接完整预览、大图和金额键盘；模拟器不能代替这些真机体验。
